# Sandbox — a falling-sand physics playground

A falling-sand physics sandbox that runs entirely in the browser. Every pixel is
a simulated particle governed by simple cellular-automata rules — draw sand,
water, fire, oil, acid, plants and more, and watch them interact: water douses
fire, fire races through oil, acid eats stone, plants drink water and burn.

**Pure HTML + CSS + JavaScript + Canvas. No game engine, no libraries, no build
step, no accounts.** Open `index.html` and play.

> Work in progress — see the roadmap below.

## Run it

Just open `index.html` in any modern browser. That's it.
